# 2020S_FE_AM_1
For two 8-bit signed integers A and B in 2's complement format, which of the following will cause an overflow when the addition of A and B is executed?

|  | A | B |
| --- | --- | --- |
| a) | 0111 1111 | 1111 1110 |
| b) | 0111 1111 | 0111 1110 |
| c) | 1000 0000 | 0111 0000 |
| d) | 1111 1111 | 1111 1111 |

a) A = 0111 1111, B = 1111 1110
b) A = 0111 1111, B = 0111 1110
c) A = 1000 0000, B = 0111 0000
d) A = 1111 1111, B = 1111 1111
?
b) A = 0111 1111, B = 0111 1110
