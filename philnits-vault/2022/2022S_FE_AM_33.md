# 2022S_FE_AM_33
In IPv4, what is the maximum number of IP addresses that can be assigned to hosts in
the network of 172.16.64.0/23? Here, the decimal number after the slash (/) is the number of
bits used for the network prefix.

a) 254
b) 256
c) 510
d) 512
?
c) 510
