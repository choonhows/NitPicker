# 2016S_FE_AM_19
When the multiplicity of processing is increased in the virtual memory of a computer
system, page-in and page-out operations occur very frequently, and the response speed of the
system decreases suddenly. What is this phenomenon called?

a) Memory compaction
b) Overlay
c) Roll-out
d) Thrashing
?
d) Thrashing
