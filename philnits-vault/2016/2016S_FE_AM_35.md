# 2016S_FE_AM_35
TCP/IP is a layered set of communication protocols consisting of the Network Interface
layer, the Internet layer, the Transport layer, and the Application layer. Which of the
following is a combination of the Transport layer protocols?

a) DHCP, TCP
b) HTTP, UDP
c) IP, TCP
d) TCP, UDP
?
d) TCP, UDP
