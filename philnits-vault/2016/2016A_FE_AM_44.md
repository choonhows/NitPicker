# 2016A_FE_AM_44
Which of the following is a technique where a system is actually attacked and an
intrusion attempt is made in order to detect security-related vulnerabilities of a computer or
network?

a) Penetration test
b) Regression test
c) Software inspection
d) Walk-through
?
a) Penetration test
