# 2016A_FE_AM_28
In the process of table implementation, which of the following is an appropriate SQL
statement that removes a column in an existing table?

a) ALTER TABLE table_name DELETE COLUMN column_name
b) ALTER TABLE table_name DROP COLUMN column_name
c) UPDATE TABLE table_name DELETE COLUMN column_name
d) UPDATE TABLE table_name DROP COLUMN column_name
?
b) ALTER TABLE table_name DROP COLUMN column_name
